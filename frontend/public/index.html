TempPad

Create a temporary public text file by choosing a name.

Letters, numbers, hyphens, and underscores only. 1–64 characters. No spaces or dots.

How it works

  • Files are public — anyone with the link can read and edit
  • Files expire 24 hours after creation — the timer never resets
  • Content is temporary — it will be permanently deleted
  • Do not store passwords, keys, or sensitive data
  • Anyone with the link can edit — the latest save wins
